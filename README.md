# Shailesh Art Studio Website

A beautiful, responsive website for Shailesh Art Studio featuring a blue, yellow, and green color theme.

## Features

### Pages Included:
1. **Home** - Hero section with beautiful background and featured artworks
2. **About** - Artist profile with photo, biography, and journey timeline
3. **Gallery** - Artwork showcase with frames and filter functionality
4. **Commissioning** - Custom painting services with pricing and process
5. **Blog** - Art-related articles and insights
6. **Contact** - Contact form and studio information

### Design Features:
- **Color Theme**: Blue (#2563eb), Yellow (#fbbf24), Green (#10b981)
- **Social Media Icons**: Facebook and Instagram icons on every page (top-right corner)
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Elements**: Hover effects, smooth scrolling, animations
- **Gallery Filter**: Filter artworks by category (Abstract, Landscape, Portrait, Urban)
- **Contact Form**: Functional contact form with validation
- **Newsletter Subscription**: Email subscription form on blog page

## How to Use

1. **Open the Website**: Simply open `index.html` in any web browser
2. **Add Your Images**: Replace placeholder images in the `images/` folder
3. **Customize Content**: Edit the HTML files to add your own content
4. **Update Social Links**: Replace Facebook and Instagram URLs with your actual profiles

## Customization Guide

### Adding Your Own Images:

1. Add images to the `images/` folder
2. Update the image placeholders in HTML files:
   - Hero background on home page
   - Artist photo on about page
   - Artwork images in gallery
   - Blog post images

### Updating Social Media Links:

Find these lines in each HTML file and replace with your actual URLs:
```html
<a href="https://www.facebook.com" target="_blank">
<a href="https://www.instagram.com" target="_blank">
```

### Changing Colors:

Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-blue: #2563eb;
    --primary-yellow: #fbbf24;
    --primary-green: #10b981;
}
```
